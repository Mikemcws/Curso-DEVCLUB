## 📋 Sobre o Projeto

Projeto desenvolvido durante o **Curso DEVCLUB** - uma jornada intensa de aprendizado em desenvolvimento web. 

Aqui aplico na prática os conceitos fundamentais de **HTML**, **CSS** e **JavaScript** para construção de interfaces modernas e responsivas.

<br>

## 🎯 Objetivos

- [x] Estruturar páginas com HTML semântico
- [x] Estilizar com CSS moderno
- [x] Adicionar interatividade com JavaScript
- [ ] Implementar responsividade completa
- [ ] Publicar o projeto final
